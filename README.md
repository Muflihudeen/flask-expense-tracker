# Flask Expense Tracker 

A Flask-based expense tracking web application with SQLite database integration.

## Features
- Add income and expenses
- Delete transactions
- Transaction categories
- Dynamic balance calculation
- SQLite database storage
- Responsive web interface

## Technologies Used
- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS

## How to Run

1. Install dependencies

pip install flask flask_sqlalchemy

2. Run the application

python app.py

3. Open browser

http://127.0.0.1:5000
